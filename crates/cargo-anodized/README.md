# Cargo, Anodized

Cargo integration for [Anodized](https://github.com/anodized-rs/anodized).

## Installation

```bash
cargo install cargo-anodized
```

## Subcommands

- `fmt`: Run `rustfmt` and `anodized-fmt` on a Cargo project.
